# Northwind Functions Exercises

این ریپو شامل تمرین‌های عملی برای **توابع اسکالر و Table-Valued Function در SQL Server** است، با استفاده از دیتابیس **Northwind**.

---

## 🎯 هدف تمرین

هدف این تمرین:

- یادگیری ساخت **Scalar Function** در SQL Server  
- یادگیری ساخت **Table-Valued Function** (TVF)  
- محاسبه و نمایش **سود محصولات و سفارشات مشتریان**  
- تمرین کوئری‌های عملی روی دیتابیس واقعی Northwind  

---

## 📁 دیتابیس مورد استفاده

- **Northwind**: دیتابیس نمونه شرکت‌ها، محصولات، مشتریان و سفارشات  

---

## 🧰 تمرین 1: Scalar Function

**هدف:** محاسبه سود یک محصول در یک سفارش مشخص


##  🧰 تمرین 2: Table-Valued Function


هدف: نمایش تمام سفارشات یک مشتری همراه با سود هر محصول 

---

## 📝 توضیحات

- **Scalar Function**: یک مقدار سود را برای محصول و سفارش مشخص برمی‌گرداند  
- **Table-Valued Function**: جداول سفارشات مشتری را همراه با سود هر محصول نمایش می‌دهد  
- تمرین با دیتابیس **Northwind** انجام شده است  
- می‌توانید این توابع را در پروژه‌های شخصی یا آموزشی توسعه دهید

---

## 🎯 مخاطبان

- دانشجویان و علاقه‌مندان SQL Server  
- توسعه‌دهندگان Backend  
- مهندسان دیتابیس و DBAها  
- کسانی که می‌خواهند توابع اسکالر و Table-Valued Function را تمرین کنند
